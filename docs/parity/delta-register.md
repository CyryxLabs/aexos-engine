## AEXOS 1.0 source and distribution transition

The owner's closing direction restarts the product at 1.0.0 and authorizes a new public GitHub history. The prior repository is retained as a private archive, including branches and pull requests. No old package publication is revoked or silently redefined. Local runtime state, previous binaries and execution logs are excluded from the new source export; reusable configuration, operational content, tests, licenses and upstream provenance remain.

The installed legacy scenario now measures an explicitly selected artifact transition from the integrity-pinned public 5.3.0 release to the candidate's actual version, using the existing forced updater path. It still checks package/manifest versions, SYNAPSE bytes, lockfile replacement, custom configuration/file preservation and Doctor. It no longer calls this a same-version repair. Automatic npm update discovery is a separate behavior.

The `next` task regression executes the packaged Markdown recommendation/formatting steps with real state manager and suggestion engine modules. Blocked-state output must contain its handoff once, and unknown state must retain explicit guidance. Task audit/cleanup now retain original relative paths in their archive manifest; PostgreSQL tasks no longer advertise Neo4j prerequisites, and project module imports are anchored to an explicit project root.
