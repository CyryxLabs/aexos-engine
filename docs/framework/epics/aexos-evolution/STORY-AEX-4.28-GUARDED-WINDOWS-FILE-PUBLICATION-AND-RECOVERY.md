## Story

**As an** AEXOS operator on an explicitly supported Windows host, **I want** governed exclusive file creation and recoverable replacement beneath the existing structured filesystem boundary, **so that** installed SDLC journeys can publish bounded bytes without escaping the authorized project, overwriting a concurrent file, or concealing mutation and recovery state.

## Operation semantics

### `guarded-create`

`guarded-create` publishes a new regular single-link file only when the destination name is absent. It validates and pins the supported volume-to-authorized-root-to-parent chain by component handles, creates private staging bytes exclusively in the pinned destination directory, verifies the staged content, and publishes the staged handle to the requested leaf with replacement forbidden. A destination collision is a pre-acceptance conflict: the existing destination and every outside sentinel remain unchanged, and no successful/accepted result is emitted.

### `guarded-recoverable-replace`

`guarded-recoverable-replace` is a conditional, recoverable transaction for a pre-existing regular single-link file. It locks the exact target, verifies the caller-approved expected-before file identity and binary hash while that lock remains held, prepares an integrity-checked immutable journal and binary-safe original-data recovery artifacts, parks that exact locked handle under a unique no-replace transaction name, and then publishes staged new bytes to the original name with replacement forbidden.

This operation is not an atomic old-to-new replacement. The original pathname can be absent between parking and publication. A competitor that creates the original name after parking wins the name: AEXOS must preserve the competitor, the parked original, journal, and recovery artifacts, block acceptance and downstream dispatch, and return a post-mutation recovery state. It must never report this as denied-with-no-effects.

The minimum externally visible states are `REJECTED_BEFORE_MUTATION`, `UNSUPPORTED_BEFORE_MUTATION`, `PREPARED`, `ORIGINAL_PARKED`, `PUBLISHED`, `VERIFIED`, `RECOVERY_REQUIRED`, `RECOVERED`, and `RECOVERY_CONFLICT`. Every result identifies the last durable/reconstructable phase and the exact classes of effects that may exist.
